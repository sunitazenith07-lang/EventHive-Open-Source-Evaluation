# Evaluation workflow

Fork this repository, create a focused branch, make a small change, run `python -m pytest -q`, and open a pull request to the original repository. Do not merge it. In the PR explain root cause, behaviour changed and test evidence. Watch the Actions check attached to the PR.

AI chatbots, generated code, AI completion and solution-sharing are prohibited for this evaluation. Standard non-AI documentation is allowed. Do not submit code you cannot explain; a short live modification may be requested.
