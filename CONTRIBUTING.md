# Contribution guide

- Start only after the organiser announces kick-off.
- Reproduce each reported issue before coding.
- Use focused branches: fix/issue-<number>-<summary> and feature/<short-name>.
- Run python -m pytest -q; do not delete or weaken tests.
- Open pull requests with root cause, summary, tests run and known limitations.
- Be prepared to explain and modify your code in the viva.
